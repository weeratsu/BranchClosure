# Branch Closure Checklist (เช็คลิสต์เก็บอุปกรณ์ปิดสาขา)

เว็บเช็คลิสต์แบบไฟล์เดียว (single-file, offline-first) สำหรับงานเก็บอุปกรณ์ POS/PC ตอนปิดสาขา
ออกแบบให้เปิดบนมือถือได้ (iPhone-friendly) และเพิ่มลง Home Screen เป็น PWA-style ได้

## คุณสมบัติ

- ✅ เช็คลิสต์ 10 ขั้นตอนต่อสาขา (รอยืนยัน Adjust, เก็บ POS/PC, ถอด LAN, ส่ง Checklist ฯลฯ)
- 🧳 รายการ "ของที่ต้องเอาไป" แบบติ๊กได้ (เครื่องมือ / วัสดุแพ็ก / เอกสาร)
- 🏪 เลือกสาขาจากรายการสำเร็จรูป (รหัส + ชื่อ + จำนวน PC/POS) หรือพิมพ์เพิ่มเอง
- 🖼️ ตัวอย่างรูป + คลิปสาธิต (ใส่กล่อง POS, ติด Label PC, ถอดสาย LAN Port 23/24)
- 📊 แถบความคืบหน้ารวม
- 💾 บันทึกสถานะอัตโนมัติในเครื่อง (localStorage)
- ⬇️⬆️ Export / Import ย้ายสถานะข้ามเครื่อง (ไฟล์ JSON)
- 🖨️ พิมพ์ / บันทึก PDF

## วิธีใช้

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

**บน iPhone:** เปิดใน Safari → ปุ่มแชร์ → **Add to Home Screen** → เปิดเหมือนแอปเต็มจอ

> หมายเหตุ: หน้าเว็บอ้างอิงรูป/คลิปจากโฟลเดอร์ `images/` แบบ relative path
> เพื่อให้รูปแสดงได้ ต้องเปิดโดยมีโฟลเดอร์ `images/` อยู่ข้างๆ `index.html`
> (เปิดผ่าน local web server หรือ sync ทั้งโฟลเดอร์ลงเครื่อง)

## โครงสร้าง

```
BranchClosure/
├── index.html      ← ตัวเช็คลิสต์ (เปิดไฟล์นี้)
├── images/         ← รูปตัวอย่าง + คลิปสาธิต
└── files/          ← เอกสารอ้างอิง (แผนเก็บ PC ฯลฯ) — ไม่จำเป็นต่อการรันเว็บ
```

## การปรับแต่ง

แก้รายการได้ที่ส่วน `<script>` ใน `index.html`:
- `STEPS` — ขั้นตอนต่อสาขา
- `PACK` — รายการของที่ต้องเอาไป
- `ALL_BRANCHES` — รายชื่อสาขาในตัวเลือก

## หมายเหตุความเป็นส่วนตัว

- โค้ดไม่มีข้อมูลส่วนบุคคล hardcode ไว้ (ไม่มีชื่อผู้รับผิดชอบ, ไม่มี default เป็นสาขาของใครคนใดคนหนึ่ง)
- สถานะที่ติ๊กทั้งหมดเก็บใน localStorage ของเบราว์เซอร์เท่านั้น ไม่ถูกส่งออกไปไหน
- ⚠️ โฟลเดอร์ `images/` และ `files/` มีรูปหน้างานจริงและเอกสารแผนงาน — ดูหัวข้อถัดไปก่อน push
